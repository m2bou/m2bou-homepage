# M2坊 リンクページ v3

今回の方針は「最新作 → 過去作品 → 支援サイト → SNS」です。

## URLの設定
`index.html` 最下部の `const LINKS = {...}` に各URLを入力してください。

- latestFanza / latestDlsite: 3作目
- work2Fanza / work2Dlsite: 2作目
- work1Fanza / work1Dlsite: 1作目
- allWorks: 作品一覧ページ（不要なら空欄のままで可）
- fanbox / fantia / cien: 支援サイト
- x / pixiv / instagram: SNS

空欄のリンクは半透明になり、クリックできません。
